# Vectoplan (v0.5 bêta)

Transforme un plan scanné ou un PDF en dessin vectoriel (DXF) pour AutoCAD.
Tout le traitement se fait dans le navigateur : aucun fichier n'est envoyé sur un serveur.

**Version 0.5 bêta, toujours en développement.** Ça fonctionne déjà, mais la détection demande encore des corrections sur les scans abîmés.
Les retours sont les bienvenus (ce qui marche, ce qui bloque, les fonctions souhaitées) : ouvre une [issue](https://github.com/Esteban1082/vectoplan/issues/new).

Essayer : https://esteban1082.github.io/vectoplan/
